# Tarkov Field Guide

Безопасный локальный помощник для подготовки к рейдам в Escape from Tarkov. Он содержит планировщик целей, чек-лист снаряжения, тренировочный таймер и заметки.

Приложение принципиально не взаимодействует с процессом игры, не читает память, не показывает игровой оверлей и не обходит античит. Данные сохраняются локально в `localStorage` браузера.

## Готовый Windows `.exe`

Приложение можно собрать в один файл `TarkovFieldGuide.exe`. Для этого на
Windows установите [Python 3](https://www.python.org/downloads/), затем дважды
нажмите `build-windows.bat`. Скрипт сам создаст изолированное окружение,
установит инструменты сборки и положит результат сюда:

```text
dist\TarkovFieldGuide.exe
```

В исполняемый файл включаются `index.html`, `styles.css` и `app.js`. Отдельный
локальный сервер и установка Python на компьютере игрока не нужны. Окно
рендерится системным Microsoft Edge WebView2, который предустановлен в
современных версиях Windows 10 и Windows 11.

### Сборка через GitHub Actions

Workflow **Build Windows executable** запускается вручную на вкладке Actions
или автоматически при отправке тега `v*`. Готовый `.exe` появится в артефакте
`TarkovFieldGuide-Windows`.

## Запуск веб-версии

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.
