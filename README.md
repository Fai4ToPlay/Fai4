# Skyline Web Runner

Оригинальный мобильный Unity-прототип скоростного перемещения по процедурному городу. Проект не содержит ассетов или кода сторонних игр.

## Архитектура

`Runtime` разделён на ввод, движение, конечный автомат, физический swing, поиск реальной точки крепления, визуализацию троса, способности, камеру, город/стриминг и диагностику. Настройки traversal находятся в `WebSwingSettings` ScriptableObject. `ProjectBootstrap` при первом открытии создаёт `WebSwingPlayground`, персонажа, разнообразные здания и Android build settings.

## Запуск и управление

1. Откройте корень проекта в Unity `6000.0.40f1` (Unity 6 LTS) с Android Build Support.
2. Дождитесь импорта: сцена создаётся автоматически. Откройте `Assets/_Project/Scenes/WebSwingPlayground.unity`.
3. Play: **WASD**, **Shift**, **Space**, мышь, **ЛКМ удерживать** (swing/release), **ПКМ** (zip), **Q/E/Ctrl** (trick input).
4. APK из Editor: `Skyline > Build Android APK`; результат — `Builds/Android/SkylineWebRunner.apk`.
5. Headless-сборка: `UNITY_PATH=/путь/к/Unity ./scripts/build-android.sh`. `UNITY_PATH` может указывать на исполняемый файл, папку `Editor` или `Unity.app`; без переменной скрипт проверяет `PATH` и стандартные каталоги Unity Hub. Скрипт удаляет устаревший APK перед сборкой, показывает хвост Unity-лога при ошибке, проверяет новый APK-контейнер и печатает его SHA-256. Unity компилирует C# через IL2CPP в нативные ARM64-библиотеки и упаковывает проект в единственный устанавливаемый APK с LZ4HC-сжатием и High Managed Stripping.

На мобильном левая нижняя зона является стиком, середина экрана — camera swipe, большая правая нижняя зона — Swing, верхние правые зоны — Zip и Jump. Физика троса удаляет только наружную радиальную скорость, сохраняя тангенциальный импульс; момент release определяет баллистическую траекторию.

## Ограничения проверки

Сцену и APK генерирует Unity Editor, поэтому физический десятикратный прогон и Android-сборку необходимо выполнять в установленном Editor. Developer HUD показывает состояние, скорость, вектор, anchor, score, длину троса и руку для настройки такого прогона.
