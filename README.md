# Tarkov Field Guide

Безопасный локальный помощник для подготовки к рейдам в Escape from Tarkov. Он содержит планировщик целей, чек-лист снаряжения, тренировочный таймер и заметки.

Приложение принципиально не взаимодействует с процессом игры, не читает память, не показывает игровой оверлей и не обходит античит. Данные сохраняются локально в `localStorage` браузера.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.
